# Eunji Office

A web application for Woong Office with various features like Todo list, Food selector, Calendar, and Reminder.

## Setup and Run

1. Install dependencies:
```
npm install
```

2. Start the server:
```
npm start
```

3. For development with auto-restart:
```
npm run dev
```

4. Open your browser and navigate to `http://localhost:3000`

## Features

- Todo List
- Food Selector
- Reminder/Compliments
- Calendar/Dates
